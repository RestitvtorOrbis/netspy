## Decisions and contracts

The new internal test-only support class provides the existing reflection-based C# factory using `Assembly.Load("dnSpy.Decompiler.ILSpy.Core")`, the real `dnSpy.Decompiler.ILSpy.Core.CSharp.DecompilerProvider` type, and selection by `UniqueGuid == DecompilerConstants.LANGUAGE_CSHARP_ILSPY`. Reuse it from the two existing tests, removing only their now-duplicate factory code. It also composes `DsDocumentService`, `DefaultDsDocumentProvider`, and `BundleDsDocumentProvider` via `TypeCatalog`; export only the existing settings instance needed by that service. Discover the bundle provider through its MEF export, not `new BundleDsDocumentProvider()` added as an exported value. Use the production node provider and `IDecompileSelf` for a selected managed entry, plus decompile a type containing a method body so success is more than assembly metadata text.

The existing ordinary regression's settings export incorrectly uses inferred generic type `object`, which creates `System.Object` export type identity and rejects service composition. Replace its private composition helper with the shared correct helper: add an explicit `System.ComponentModel.Composition.Primitives.Export` whose contract name is the internal settings interface's full name and whose metadata `ExportTypeIdentity` is `AttributedModelServices.GetTypeIdentity(settingsContractType)`, returning the real settings instance. Keep the real service constructor and provider discovery. This is a test composition fix, not a product MEF change.

`CSharpDecompiler.Decompile(AssemblyDef)` deliberately emits assembly-level metadata only. Both existing decompiler regressions currently assert method-body strings against that output and must be corrected: keep assembly identity/header assertions on assembly output; obtain the fixture's `Program` type and separately call `Decompile(TypeDef, ...)` before asserting `Console.WriteLine`, `BUNDLE_VALUE=`, or `ORDINARY_EXE`. Do not change production managed-entry selection semantics to satisfy an incorrect assertion. The same distinction applies to the new generated pipeline test below.

Generated test: locate existing `Net10/artifacts/net10.0/scd-compressed/publish/SingleFile.App.exe` from repository ancestors, open through composed document service, assert `BundleDsDocument`, find `SingleFile.App.dll`, select its managed node, assert expected `BUNDLE_VALUE=` and `Console.WriteLine` output using existing fixture assertions, and decompile a method-bearing type. Preserve the existing test that proves unopened entries stay lazy; do not duplicate that coverage. Keep existing ordinary DLL/EXE regression in the same CI gate.

External test (Windows SDK/CI-only): `NETSPY_EXTERNAL_BUNDLE` is an opt-in path. Absent/empty variable explicitly skips via the xUnit v3 supported runtime skip API, not a passing early return. Any explicitly configured invalid path (missing, unreadable, directory or invalid bundle) fails. Hash source before and after; open through the same MEF service; choose an assembly entry whose basename equals the executable basename plus `.dll`, require a unique match, activate it and decompile one type with a method body using the real C# decompiler. Assert nonempty output and lack of decompiler error diagnostics; do not print or persist decompiled source. For the user's Hand2Note path record only status/counts/hash nonmutation, not proprietary source. Other bundle basename layouts are outside this narrow smoke contract.

Local limitation/fallback: Windows has .NET 10/WPF runtimes but no SDK/MSBuild; `dotnet test <project> --no-build --no-restore` still requires an SDK. Linux SDK 10.0.111 cannot host these WPF-dependent Windows tests. Therefore the external xUnit command below is for a Windows SDK host only. Locally, require the existing Windows runtime diagnostic using existing Debug binaries over a WSL UNC path, with before/after SHA256 of the original, where available. Record the diagnostic invocation/artifact identity, provider/module counts, output lengths/error status and both hashes; retain available prior evidence if rerunning is impossible and identify missing evidence explicitly. The master records the prior 136-entry/36-type, 1157/4929-character result; do not invent a hash or label it an external xUnit pass. No proprietary source output is retained. Missing local SDK is an environmental limitation, not the absent-variable skip; an invalid configured path remains failure.
